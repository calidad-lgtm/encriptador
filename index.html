Configuración

Código de recuperación

Se agrega en secreto a cada archivo que proteges. Si alguien pierde la clave, este código lo abre. No se muestra en la app y solo se guarda en este equipo.

Si tu oficina usa un código común (por ejemplo, uno que guarda la jefatura), ingrésalo con «Usar un código existente». Los archivos ya protegidos siguen abriéndose con el código que tenían.

Instructivo

Proteger un archivo

  1. En Proteger, elige o arrastra el archivo.
  2. Usa la clave generada o escribe la tuya.
  3. Pulsa Proteger y descargar. Se descarga un archivo .protegido.html que ya trae las instrucciones para abrirlo.
  4. Envía ese archivo. La clave va por otro medio (teléfono o WhatsApp).

Abrir un archivo recibido

  1. Abre el archivo .protegido.html con doble clic.
  2. Escribe la clave y pulsa Abrir archivo.
  3. Se descarga el archivo original, listo para usar.

También puedes cargarlo en la pestaña Abrir de esta app (acepta .protegido.html y .enc).

Si se pierde la clave

En Abrir, pulsa «Olvidé la clave: usar mi código de recuperación». Solo funciona en el equipo de quien protegió el archivo, o con su kit de recuperación.

Instalar la app

Chrome o Edge: botón Instalar arriba, o el ícono de instalar en la barra de direcciones. Safari (Mac): Archivo → Añadir al Dock. iPhone/iPad: Compartir → Añadir a pantalla de inicio.

Importante: si se pierden la clave y el código de recuperación, el archivo no se podrá abrir. Nadie puede recuperarlo.
